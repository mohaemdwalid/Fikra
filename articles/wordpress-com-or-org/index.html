Choosing a platform

What is the difference between WordPress.com and WordPress.org?

By FIKRA · Updated 16 October 2026 · 2 min read

WordPress.org is the software project; WordPress.com is a hosted service. Ask which arrangement the quote means before comparing features and costs.

In this guide
  1. Why the distinction matters in a quote
  2. Clarify the proposal
  3. Check control and support
  4. Test the publishing task
  5. Inspect the actual contract

Why the distinction matters in a quote

A proposal for self-hosted WordPress must explain the host and who maintains the software. A hosted-service proposal must specify the plan and its actual access to plugins, code and support. Do not assume the same capabilities merely because both use WordPress. Ask the supplier to demonstrate the page types, languages and commerce you need, then explain exports, renewals and changing providers. The familiar name should not hide a different responsibility or subscription model.

Clarify the proposal

Ask whether the project uses self-hosted WordPress or a particular hosted service plan. Identify who manages hosting, software, backups and extensions. Features available in one arrangement should not be assumed for the other.

Check control and support

Review access to plugins, custom code, exports and support in the actual service terms. Record renewal responsibility and the consequences of changing providers. Keep recovery access with the business rather than relying only on an agency account.

Test the publishing task

Try creating the page types and languages you need. If ecommerce is required, include the complete commerce setup in the demonstration. Choose based on the supported workflow and the owner’s responsibilities, not simply the familiar WordPress name.

Inspect the actual contract

Identify the service, plan, host and extension permissions in the proposal. Ask who handles updates, backups and migration, and what access you receive. The shared WordPress name does not mean two offers include the same control or support; compare the arrangement being sold rather than its label.
