Products and collections

How do you prepare a Shopify product CSV import?

By FIKRA · Updated 16 October 2026 · 2 min read

Use a small trial import first. A spreadsheet mistake can affect prices, options and existing products, not just the appearance of a page.

In this guide
  1. What your sample should contain
  2. Create a consistent source sheet
  3. Use representative test products
  4. Reconcile after import
  5. Keep a small reference file

What your sample should contain

Include one simple product, one with several variants and one with multiple photos. After importing, open the actual product pages and compare names, SKUs, prices and images with the approved sheet. Check the overwrite settings before touching an existing catalogue. If the sample has a mismatch, correct the source instead of manually repairing hundreds of pages later. Record the file version used so you can trace any unexpected change.

Create a consistent source sheet

Standardise product names, handles, SKUs, options and image references. Separate your working spreadsheet from the file prepared for Shopify. Use the current Shopify CSV format and review its column requirements rather than inventing headers. Preserve identifiers that your fulfilment or stock process relies on.

Use representative test products

Include a simple product, a product with several variants and an item with multiple images. Check the import preview and then inspect the resulting product pages, prices and options. Confirm that image links are reachable. Do not take a successful upload message as proof that the catalogue is correct.

Reconcile after import

Compare product and variant counts with the approved source. Spot-check high-value items and check for duplicate handles or missing photos. Keep an exception list with a named owner. Only expand the import after the sample behaves as expected, and record the exact source version used.

Keep a small reference file

Prepare a few representative products, including options and special characters, and import them first. Review names, images, prices and inventory before scaling up. Keep the original export and a record of the changes so a large import can be understood and corrected instead of repeated blindly.
