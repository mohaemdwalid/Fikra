## Editing and artwork

Edit `content/articles/<slug>.json`, preserving original publication dates and updating modification dates only when changing content. The existing public build generates both language versions, metadata and sitemap entries. `scripts/articles.py` maintains the library, language links and related articles. General website articles link to FIKRA’s actual Shopify work rather than advertising unconfirmed WordPress services.

Each topic has its own 1200 × 675 WebP illustration, displayed on article pages and library cards, with translated alt text and social/structured-data image references. Original SVG sources remain private in `content/article-art/`; public WebP files live in `assets/article-images/`.

The 100 images total approximately 992 KiB. Normal site builds use the existing images and do not need browser rendering. `scripts/build_article_art.py` plus `scripts/article_art_expansion.py` draw the source diagrams; `scripts/render_article_art.cjs` regenerates WebP using isolated Chrome/Playwright and Pillow.
